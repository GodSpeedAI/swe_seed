# Core Playbooks

These playbooks are small, composable procedures for work that benefits from a repeatable human-readable pattern but should not become another command. They do not replace `just`, route cards, Skill IR, or validation.

Use them in order when useful:

1. `00-orient-and-route.md`
2. `10-frame-outcome.md`
3. `20-change-with-proof.md`
4. `30-debug-from-symptom.md`
5. `40-review-for-risk.md`
6. `50-capture-learning.md`

Do not add a seventh core playbook without removing or merging an existing one. If a procedure becomes strict and reusable enough to enforce, convert it into Skill IR or validation.
